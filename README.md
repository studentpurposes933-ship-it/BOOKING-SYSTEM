# 🤖 AI-Powered Smart Appointment Booking System

A complete, production-ready, full-stack **AI-Powered Smart Appointment Booking System** featuring conversational AI booking, real-time FullCalendar synchronization, atomic double-booking prevention, and Firebase Authentication & Firestore.

---

## 🌟 Key Features

### 🧠 AI Booking Assistant
- **Natural Language Understanding**: Powered by Google Gemini AI. Parse requests like *"Book tomorrow at 10 AM for a meeting with HR"* into structured booking data.
- **Persistent Booking Draft**: Remembers collected details (date, time, purpose) across multiple conversation turns — never asks twice for the same field.
- **Smart Date & Time Parsing**: Correctly handles formats like `14 08 2026 at 10am`, `Thu, 13 Aug`, `Aug 14`, `tomorrow`, `Friday` without confusing date numbers with times.
- **12-Hour AM/PM Format**: All times shown as `10:00 AM`, `2:00 PM`, `4:00 PM` — never 24-hour format.
- **Short AI Messages**: Responses are 1–2 sentences. No verbose paragraphs or raw variable names.
- **Deterministic Response Messages**: All AI chat messages are generated by a deterministic template engine — Gemini AI is only used for parsing, never for generating user-visible text directly. This prevents raw variable names (`startTime`, `purpose`, etc.) from ever appearing in chat.

### 💡 Smart Suggestion Chips
- **Grouped by missing field** with labeled sections:
  - 📅 **When?** → Today · Tomorrow · Friday · Monday
  - 🕐 **What time?** → 9:00 AM · 10:00 AM · 12:00 PM · 2:00 PM · 4:00 PM
  - 📌 **What for?** → Meeting with HR · Consultation · Project Review · Interview · Team Sync · Design Audit
- **Context-aware**: Chips update based on what info is already collected — once a date is known, only time and purpose chips show.
- **Quick-book buttons**: When idle, shows one-tap full-booking examples like `Today · 10 AM · Meeting`.
- **Alternative slot chips**: When a slot is booked, shows available alternatives with golden styling. Clicking an alternative correctly resets the draft so the new time is parsed fresh (fixes infinite conflict loop).

### 🔄 Rotating Placeholder
The input box cycles through real examples every 3.5 seconds:
- *"e.g. Book tomorrow at 10 AM for a meeting"*
- *"e.g. Friday at 2 PM for a consultation"*
- *"e.g. Today at 9 AM for an interview"*
- *"e.g. Monday at 4 PM for a project review"*
- *"e.g. Book Aug 15 at 11 AM"*

### ✅ Post-Booking Flow
After a booking is confirmed, the success card offers two actions:
- **🗓️ Book Another** — Resets everything instantly and starts a fresh conversation.
- **✓ Done** — Shows a warm thank-you message and returns to idle.

### 📅 Real-Time Calendar
- **Day / Week / Month** views via FullCalendar 6.
- Firestore `onSnapshot()` — zero-refresh real-time sync across all browser windows.
- **Live sync status badge** with 5-second countdown timer.

### 🔒 Atomic Double-Booking Prevention
All bookings run through a Firestore Transaction (`runTransaction`), enforcing:

$$\text{newStart} < \text{existingEnd} \quad \text{AND} \quad \text{newEnd} > \text{existingStart}$$

No race conditions, no duplicate slots.

### 🔐 Firebase Authentication
- Email & password registration / login with persistent auth state.
- **Password visibility toggle** (Eye / EyeOff icons).
- User profiles stored in `users/{uid}` Firestore documents.
- Backend `verifyToken` middleware validates Firebase ID Tokens on all protected routes.

### 🔀 Alternative Time Slots
- Automatically suggests available slots during working hours (Mon–Fri, 09:00 AM – 05:00 PM) when the requested slot is taken or out of hours.
- Clicking an alternative chip correctly clears the previous conflicting time from the draft before sending.

## 🔒 Firestore Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /appointments/{appointmentId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null && request.resource.data.userId == request.auth.uid;
      allow update, delete: if request.auth != null && resource.data.userId == request.auth.uid;
    }
    match /blockedSlots/{blockedSlotId} {
      allow read: if request.auth != null;
      allow create, update, delete: if request.auth != null;
    }
  }
}
```

## 💬 AI Booking Flow

```
User: "Book tomorrow at 2 PM for a consultation"
  │
  ↓ POST /api/ai/chat  (with currentDraft)
  │
  ↓ Gemini parses → { date, startTime, purpose }
  │
  ↓ mergeBookingDraft() → merges with existing draft
  │
  ├─ Missing fields? → Deterministic question + suggestion chips
  │
  └─ All fields present?
       │
       ├─ Outside working hours? → Show alternative slots
       │
       ├─ Conflict? → Show alternative slots (draft startTime cleared)
       │
       └─ Available → Show compact confirmation card
            │
            └─ User clicks "Confirm Booking"
                 │
                 └─ clientBookingService.createClientAppointmentAtomic()
                      │
                      └─ Firestore runTransaction → write to appointments/
                           │
                           └─ onSnapshot → FullCalendar updates instantly
```
